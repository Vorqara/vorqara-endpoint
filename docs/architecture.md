# Vorqara Endpoint Architecture

## Overview

Vorqara Endpoint is an enterprise-grade Endpoint Detection and Response (EDR), Remote Monitoring & Management (RMM), and Remote Desktop platform designed using a modular microservice-ready architecture.

## Backend Stack

- NestJS
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Swagger OpenAPI

## Frontend Stack

- React
- TypeScript
- TailwindCSS
- React Query
- React Router

## Infrastructure

- AWS
- Docker
- GitHub Actions
- Terraform
- Nginx
- S3
- CloudFront
- RDS PostgreSQL

## Core Modules

- Authentication
- Organizations
- Users
- RBAC
- Endpoint Management
- Remote Desktop
- Patch Management
- Software Inventory
- Policies
- AI Assistant
- Audit Logs
- Notifications
- Reporting

## Security Principles

- Zero Trust
- Least Privilege
- Multi-Tenant Isolation
- JWT Authentication
- Password Hashing (bcrypt)
- Audit Logging
- Secure API Design
