# Vorqara Endpoint

Vorqara Endpoint is the first product in the Vorqara platform ecosystem.

It provides modern Remote Monitoring & Management (RMM), endpoint security, remote support, asset management, compliance monitoring, and automation for organizations of all sizes.

## Project Structure

```
backend/      Backend API (NestJS)
frontend/     Web Dashboard (React)
shared/       Shared libraries and types
agent/        Endpoint Agent
installer/    Agent installer and packaging
docker/       Docker configuration
docs/         Technical documentation
scripts/      Development and automation scripts
```
